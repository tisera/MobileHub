# Mobile Hub    
## Project Description
Mobile Hub is a website designed to help users explore and compare different mobile phones. The platform provides information about various phones, including their specifications, features, prices and performance. Users can easily search, filter and view phone details to make better decisions when choosing a mobile device. This project was developed as a group project where each member worked on a separate branch before merging the final project.

##Features
### 1. Homepage
Provides the main introduction to the Mobile Hub website.
Displays featured phones and important sections of the website.
Includes navigation links that allows users to access different parts of the website.

### 2.Phone details
Allows users to compare different mobile phones.
Helps users identify differences between phones based on:
-Phone name
-Price
-Camera quality
-Storage capacity
-Processor details
-Other important features

### 3.Search and filter system
Enables users to find phones easily.
Users can filter phones according to different categories such as:
-Price range
-Brand
-Features
-Performance

### 4.Phone comparison
Allows users to compare different mobile phones.
Helps users identify differences between phones based on:
-Price
-Camera
-Performance
-Battery
-Storage

### 5.Phone features section
Provides information about the unique features of different phones.
Helps users understand what makes each phone different from others.

### 6.Responsive Design
The website is designed to work on different screen sizes including:
-computers
-Tablets
-Mobile devices

## 7.Contact section
The contact section allows users to get in touch with the Mobile Hub team.
It includes a contact form where users can enter their name, email address and message.
This features make it easy for users to send inquiries, feedback or request assistance regarding the phones and services displayed on the website.
